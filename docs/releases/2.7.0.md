Tako 2.7 adds supervised per-thread servers, validates server settings before startup, and reduces protocol overhead. Requires Rust 1.95+.

### New features

- `spawn_per_thread_supervised` returns a `PerThreadHandle` with readiness, shutdown, completion, and worker failure reporting. `PerThreadReadiness` exposes worker states for health probes. Terminal worker failures stop peers, and `serve_per_thread` returns the failure.
- Server builders provide `try_build()` and a typed `ServerConfigError` that identifies invalid settings. Startup methods validate configuration before starting work.
- TCP, UDP, and Unix socket servers accept connection limits and drain deadlines through `ServerConfig`. Tokio and Compio builders provide supervised raw transport handles and fallible startup methods.

### Fixes and performance

- Server shutdown tracks upgraded WebSocket sessions, drains them within the configured deadline, and closes remaining sessions. Per-thread startup and worker failures now propagate consistently.
- Raw TCP and Unix handlers honor connection caps; UDP drops excess datagrams when its handler limit is reached. Shutdown remains responsive when capacity is exhausted.
- HTTP dispatch attaches connection metadata only when handlers or middleware need it, reducing allocations across HTTP/1, HTTP/2, and HTTP/3 while preserving transport metadata.
- gRPC recognizes common content types without allocating a MIME parser. Buffered compression avoids copying single-frame bodies and reduces header negotiation overhead while preserving trailers and errors.
- WebSocket sends check capacity and queue messages under one lock, reducing synchronization overhead and preserving backpressure with concurrent senders.

### Upgrade notes

- Existing builder and per-thread spawn APIs remain available. Invalid server configurations now fail during startup; use `try_build()` for an explicit validation result.
- `serve_per_thread` exits with an error on terminal worker failure. Dropping a `PerThreadHandle` requests shutdown; retain it while the server is needed, and call `join()` outside the async executor to wait for worker threads.
- See the [deployment guide](https://tako.rust-dd.com/docs/deployment) for supervised workers and the [raw transport guide](https://tako.rust-dd.com/docs/transports/tcp-udp-unix) for connection limits and shutdown.
